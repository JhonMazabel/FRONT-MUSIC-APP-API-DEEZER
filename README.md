# Music Playlist App - Deezer API

Aplicación web para la gestión de listas de reproducción de música desarrollada con **Angular 17** y **PrimeNG**.

## Características
- Autenticación básica (Login/Logout).
- Creación y administración de múltiples playlists.
- Búsqueda de canciones en tiempo real utilizando la API de **Deezer**.
- Reproductor de música integrado para previsualización de tracks.
- Diseño responsivo y moderno basado en componentes **Standalone** y **Signals**.

## Tecnologías principales
- Angular 17
- PrimeNG / PrimeFlex / PrimeIcons
- RxJS
- HttpClient con Proxy para CORS

## Instalación y ejecución
1. Clonar el repositorio.
2. Instalar dependencias:
   ```bash
   npm install --legacy-peer-deps
   ```
3. Ejecutar el servidor de desarrollo:
   ```bash
   ng serve
   ```
4. Abrir `http://localhost:4200` en el navegador.
